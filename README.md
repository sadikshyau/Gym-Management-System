# Gym Management System

## Overview
A Java Swing-based desktop application designed to manage gym members, memberships, attendance, and plans. The system supports Regular and Premium members using Object-Oriented Programming principles.

## Features
- Add and manage members
- Activate and deactivate membership
- Mark attendance
- Upgrade membership plans
- File handling for data storage

## Technologies Used
Java, Swing, OOP, File Handling

## How to Run
Open the project in any Java IDE and run `GymGUI.java`.
